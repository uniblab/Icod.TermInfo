# Icod.TermInfo.Source S09 source corpus

This directory contains the deterministic source-only fixtures introduced by
S09. They complement, rather than replace, the existing T29 source/compiled
fixture pairs under `tests/Icod.TermInfo.Tests/fixtures/compiled-terminfo`.

## Valid fixtures

- `valid/system-v-basic.ti` exercises a simple System V-style entry, standard
  Boolean/numeric/string capabilities, caret notation, and ESC escapes.
- `valid/ncurses-extended.ti` exercises standard color metadata together with
  known and unknown ncurses-style extended Boolean, numeric, and string
  capabilities, escaped punctuation, spaces, ESC, and a high byte.
- `valid/inheritance.ti` exercises multiple entries, `use=` inheritance, parent
  precedence, local overrides, and cancellation.

## Malformed fixtures

- `malformed/duplicate-identities.ti` contains repeated canonical names,
  repeated aliases, alias/canonical collisions, and a case-distinct identity.
  These are recoverable warning cases; the first source-order match remains
  deterministic.
- `malformed/diagnostics.ti` collects representative recoverable lexical and
  value errors whose diagnostics must remain stable.
- `malformed/inheritance.ti` contains a direct two-entry cycle and a missing
  parent reference for resolver diagnostics.

Resource-limit and deep-inheritance adversarial cases are generated by the S09
tests so boundary sizes remain explicit and do not require large checked-in
files.

Normal tests do not invoke `tic` or `infocmp`.
