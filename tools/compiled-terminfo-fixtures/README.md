# Compiled Terminfo Fixture Generator

This is the maintainer-only generator for the deterministic compiled terminfo
corpus under `tests/Icod.TermInfo.Tests/fixtures/compiled-terminfo`.

The tool:

- requires exact `tic -V` provenance `ncurses 6.5.20250216`;
- compiles each checked-in `.ti` source with `tic -x`;
- applies the frozen Boolean-cancellation sentinel edit;
- derives the checked-in malformed/adversarial binary seeds;
- prints SHA-256 values for the regenerated corpus.

Regenerate the corpus deliberately with:

```text
dotnet run --project tools/compiled-terminfo-fixtures/Icod.TermInfo.FixtureGenerator.csproj
```

T43 adds a non-destructive pinned differential check:

```text
dotnet run --project tools/compiled-terminfo-fixtures/Icod.TermInfo.FixtureGenerator.csproj -- --check
```

`--check` snapshots the checked-in binary corpus, regenerates it through the
pinned ncurses `tic`, compares every generated byte and file name, reports drift
as an error, and restores the original checked-in bytes before exiting.

`tic` is required only for deliberate regeneration or the maintainer
differential campaign. Normal build, test, package validation, and fixture
consumption do not require `tic`, Python, or network access.
