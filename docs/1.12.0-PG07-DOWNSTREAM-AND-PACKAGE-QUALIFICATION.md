# Icod.TermInfo 1.12.0 PG07 — Downstream and Package Qualification

PG07 qualifies the 1.12 advanced persistent-raster placement semantics against stable `Icod.Terminal 1.12.0` without adding a production dependency from `Icod.TermInfo` or `Icod.TermInfo.Inspection` to Terminal.

## Qualification boundary

Production TermInfo code remains protocol-neutral. PG07 adds the Terminal dependency only to downstream qualification/sample code:

- `tools/inspection-package-smoke/Icod.TermInfo.Inspection.PackageSmoke.csproj` pins `Icod.Terminal` `1.12.0` while consuming the freshly packed Inspection package.
- `tools/inspection-package-smoke/PG07PlacementInteropSmoke.cs` executes the mapping contract on every package-smoke target framework.
- `samples/Icod.TermInfo.PersistentRasterPlacement.Sample/` demonstrates the semantic-plan-to-execution-value handoff.

No production TermInfo project references `Icod.Terminal`.

## Semantic alignment

The package-only consumer proves the two 1.12 TermInfo subjects align with the corresponding stable Terminal execution surface:

```text
PersistentRasterPlacementSubject.SourceRectangle
    -> TerminalRasterSourceRectangle
    -> TerminalRasterPlacementOptions.SourceRectangle

PersistentRasterPlacementSubject.SignedZOrder
    -> TerminalRasterPlacementOptions.ZIndex
```

The mapping is semantic only. TermInfo never owns actual rectangle coordinates or the signed z-order integer.
