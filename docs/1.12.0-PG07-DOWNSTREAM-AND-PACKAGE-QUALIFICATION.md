# Icod.TermInfo 1.12.0 PG07 — Downstream and Package Qualification

PG07 qualifies the 1.12 advanced persistent-raster placement semantics against stable `Icod.Terminal 1.12.0` without adding a production dependency from `Icod.TermInfo` or `Icod.TermInfo.Inspection` to Terminal.

## Qualification boundary

The frozen RL07 package consumer remains unchanged and continues to reference only `Icod.TermInfo.Inspection`. PG07 uses a separate downstream interoperability consumer so lifecycle qualification is not widened retroactively:

- `tools/inspection-package-smoke/Icod.TermInfo.Inspection.PackageSmoke.csproj` remains the one-package RL07 consumer.
- `tools/placement-interop-package-smoke/Icod.TermInfo.PlacementInterop.PackageSmoke.csproj` references the freshly packed Inspection package plus stable `Icod.Terminal 1.12.0`.
- `tools/placement-interop-package-smoke/Program.cs` executes the two advanced-placement mappings on every supported Inspection TFM.
- `samples/Icod.TermInfo.PersistentRasterPlacement.Sample/` demonstrates the semantic-plan-to-execution-value handoff.

No production TermInfo project references `Icod.Terminal`.

## Isolated package sources

PG07 has its own package-smoke NuGet configuration instead of weakening the established RL07 policy.

`package-smoke-pg07.NuGet.Config` maps:

```text
Icod.TermInfo*  -> freshly produced local artifacts
Icod.Terminal   -> NuGet.org
Icod.Timing     -> NuGet.org
Microsoft.*     -> NuGet.org
```

This exercises the published stable Terminal package while keeping the TermInfo side of the graph pinned to the exact Alpha-7 artifacts under qualification.

## Semantic alignment

The package-only consumer proves the two 1.12 TermInfo subjects align with the corresponding stable Terminal execution surface:

```text
PersistentRasterPlacementSubject.SourceRectangle
    -> TerminalRasterSourceRectangle
    -> TerminalRasterPlacementOptions.SourceRectangle

PersistentRasterPlacementSubject.SignedZOrder
    -> TerminalRasterPlacementOptions.ZIndex
```

The mapping is semantic only. TermInfo never owns actual rectangle coordinates or the signed z-order integer.

## Stable downstream dependency

Qualification pins the published stable package:

```text
Icod.Terminal 1.12.0
```

That release targets `net8.0`, `net9.0`, and `net10.0`, matching the Inspection package-smoke TFMs. Its published production dependencies remain `Icod.TermInfo 1.11.0` and `Icod.Timing 1.0.0`; the PG07 consumer directly references the exact Alpha-7 Inspection package, whose current TermInfo dependencies win the local qualification graph without adding any production dependency from Inspection back to Terminal.

## Sample qualification

`Icod.TermInfo.PersistentRasterPlacement.Sample` targets `net8.0`, `net9.0`, and `net10.0`. Package verification restores and executes it on all three frameworks after the package-only interoperability consumer succeeds.

The sample deliberately separates:

1. protocol-neutral lifecycle and placement planning in TermInfo; from
2. consumer-owned `TerminalRasterSourceRectangle` coordinates and signed `ZIndex` execution values.
