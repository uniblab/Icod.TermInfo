# Icod.TermInfo 1.12.0 — PG02 Immutable Placement Evidence

**Development version:** `1.12.0-Alpha-2`  
**Tranche:** PG02 — immutable placement evidence  
**Previous tranche:** PG01 — architecture, vocabulary, and public API regret gate  
**Next tranche:** PG03 — placement profile classification

## Purpose

PG02 adds the immutable evidence layer for the two advanced persistent-raster placement semantics frozen by PG01:

```text
SourceRectangle
SignedZOrder
```

This tranche deliberately does **not** classify evidence into a final support state and does not plan or execute terminal operations. It provides only deterministic, bounded facts that later PG03 classification can consume.

## Public API

PG02 adds three public types in `Icod.TermInfo.Inspection`:

```text
PersistentRasterPlacementEvidenceKind
PersistentRasterPlacementEvidence
PersistentRasterPlacementEvidenceOptions
```

`PersistentRasterPlacementEvidenceKind` has exact frozen membership and numerics:

```text
CapabilityDerived = 0
Declared          = 1
Verified          = 2
```

The vocabulary intentionally parallels the proven 1.11 lifecycle evidence precedence without modifying the frozen lifecycle enum or evidence types.

Each `PersistentRasterPlacementEvidence` value records:

```text
Subject
IsPositive
Kind
SourceLabel
SourceOrdinal
```

The value contains semantic support evidence only. It does not contain source-rectangle coordinates, z-order integers, terminal resource/placement identifiers, raw protocol fields, or live terminal ownership state.

## Validation

Construction rejects:

- undefined placement subjects;
- undefined placement evidence kinds;
- null, empty, or whitespace source labels; and
- negative source ordinals.

Evidence snapshot options freeze these bounds:

```text
DefaultMaximumEvidenceCount   = 256
MaximumSupportedEvidenceCount = 4096
```

Caller-selected bounds must remain in `1..4096`.

## Snapshot semantics

`PersistentRasterPlacementEvidence.Snapshot(...)`:

- rejects a null source collection;
- rejects null elements;
- enumerates the caller input once;
- enforces the configured evidence-count bound while enumerating;
- returns an immutable copied snapshot; and
- canonically orders evidence by:

```text
SourceOrdinal
Subject numeric value
EvidenceKind numeric value
IsPositive
SourceLabel using StringComparer.Ordinal
```

This ordering is independent of culture, hash ordering, filesystem ordering, and caller collection implementation.

## Compatibility boundary

PG02 does not modify:

- `PersistentRasterLifecycleEvidenceSubject`;
- `PersistentRasterLifecycleEvidenceKind`;
- `PersistentRasterLifecycleEvidence`;
- `PersistentRasterLifecycleProfile`;
- lifecycle request/planner semantics;
- JSON schema versions 1, 2, or 3;
- Runtime, Source, Compiler, or Termcap public APIs; or
- database-set precedence semantics.

There remains no production dependency on `Icod.Terminal`.
