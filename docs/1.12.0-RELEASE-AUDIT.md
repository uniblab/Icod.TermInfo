## Release scope

Version 1.12 adds advanced persistent-raster placement semantics and planning to `Icod.TermInfo.Inspection` without moving live graphics execution into TermInfo.

The release adds exactly two placement subjects:

```text
SourceRectangle
SignedZOrder
```

The implementation provides immutable evidence/provenance, four-state classification, deterministic lifecycle-aware placement planning, `TerminalDescription` and ordered database-set composition, and additive version-4 profile/plan JSON automation.

Concrete source-rectangle coordinates, z-order integers, resource/placement identities, wire protocol fields, terminal I/O, acknowledgements, cleanup, and live probing remain outside TermInfo.
