**Status:** UC07 COMPLETE / ACCEPTED. The exact `1.17.0` stable candidate is qualified for maintainer review.
**Publication:** 1.17.0 is unpublished. PR #48 remains draft; merge, tag, GitHub Release and package publication require separate maintainer action. Installation instructions continue to use published 1.16.0.

## Scope and contract

The [approved UC00 contract](1.17.0-UC00-UNIFIED-CATALOG-CONTRACT.md), [roadmap](../Icod.TermInfo-1.17.0-Unified-Directory-Hashed-Catalogs-Roadmap.md), [unified guide](1.17.0-UNIFIED-CATALOG-GUIDE.md), and [two-format sample](../samples/Icod.TermInfo.Catalogs.Sample/README.md) describe the accepted UC01–UC06 behavior. Catalogs reads a caller-selected conventional directory or Hash-v9 file into one bounded, read-only model. It makes no automatic format choice. The stable candidate retains the UC06 feature source; UC07 pins its API and coordinates version metadata without changing production behavior.

The [complete API freeze](1.17.0-PUBLIC-API-FREEZE.md) pins Catalogs **11** exported types (`a329380ff1c9543f822703e45cdb5158d36319bdd1317786128c1a70960c0d6f`), Inspection **108** (`930542bb475a5d8e06d68ae24d986893880c167a784e0e657ba5a1b034fd9c9f`), and BerkeleyDb **14** (`9a9a7479bbaa5f3e3ccfa0c15cfee681e665d22f727e160f9e3f632709dbdaf5`). Hashes are SHA-256 of normalized-LF UTF-8 reflection manifests. Current complete baselines and the independently frozen UC01/UC03/UC04 reconstruction checks apply to `net8.0`, `net9.0`, and `net10.0`; older 1.0–1.16 manifests remain unchanged. Reusable assembly identity remains `1.0.0.0`.

Eight coordinated package versions and release notes identify 1.17.0; seven library symbol packages accompany eight nupkg. Catalogs has exactly Runtime, Inspection, and BerkeleyDb package dependencies at the same version; tools have no Catalogs dependency. All production assemblies remain managed-only, with the established LGPL metadata. The five existing tool commands and six archive RIDs, historical JSON v1–v6 contracts, and Source Link/PDB checks remain qualification gates.

The guide specifies source provenance, `Partial` and typed failures, inclusive limits, cancellation and fresh source acquisition on each read. A blocked synchronous filesystem operation cannot be interrupted by cancellation; concurrent source replacement offers no atomic snapshot. Migration, JSON v7, new switches, implicit provider selection, and new native production dependencies are outside this release.
