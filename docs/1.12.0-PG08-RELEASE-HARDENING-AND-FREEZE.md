# Icod.TermInfo 1.12.0 PG08 — Release Hardening and Freeze

## Status

PG08 assembles the frozen `1.12.0-Alpha-8` release candidate. Exact-head validation is required before this document may describe Alpha-8 as accepted.

## Release-hardening objective

PG08 adds no new persistent-raster placement semantics. It freezes and hardens the surface produced by PG01-PG07, completes consumer/release documentation, and establishes the promotion boundary between the validated Alpha-8 candidate and stable `1.12.0`.

Stable promotion is permitted only as a release-identity/documentation transition. It may not add or change public API, JSON schema fields, lifecycle/placement semantics, production dependencies, target frameworks, command behavior, or archive RIDs.
