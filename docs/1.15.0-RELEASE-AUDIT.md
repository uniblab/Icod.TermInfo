# Icod.TermInfo 1.15.0 Release Audit

## Scope

Icod.TermInfo 1.15 is **Berkeley DB / Hashed Terminfo Acquisition**. It adds the
optional pure-managed, read-only `Icod.TermInfo.BerkeleyDb` package, explicit and
opt-in system providers, deterministic logical catalog enumeration, and reviewed
explicit-path command integration for the ncurses-compatible Hash-v9 subset.

HDB09 is the API-freeze, documentation, audit, sample, and stable-promotion
tranche. It adds no acquisition behavior or production public API beyond the
accepted `1.15.0-Alpha-8` contract.

## Dependency and distribution boundary

BerkeleyDb depends only on matching-version Runtime. Runtime and reusable sibling
packages do not depend on BerkeleyDb; Inspection remains provider-neutral.
Production contains no third-party database dependency, native binary, RID
asset, dynamic probe, or hidden download. `infocmp` and `toe` are the reviewed
direct command consumers.

The exact seven-package family, seven symbol packages, installed router smoke,
package-only net8.0/net9.0/net10.0 consumers on three hosts, and six standalone
archive RIDs remain the release topology.

## Compatibility and security

The qualified Hash-v9 contract covers little- and big-endian metadata, sorted
Hash pages, inline and overflow items, ncurses marker 0/marker 2 envelopes,
UTF-8-first and exact Latin-1 names, bounds, cancellation, permissions, and
detected two-observation mutation. It is not an atomic snapshot or general
encoding detector.

Hash writing, `tic` hashed publication, transactions, recovery, subdatabases,
other access methods/revisions, legacy type-2 Hash pages, and general-purpose
Berkeley DB APIs remain excluded.
