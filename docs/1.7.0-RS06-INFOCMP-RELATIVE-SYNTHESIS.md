# Icod.TermInfo 1.7.0 RS06 — `infocmp -u` Relative Synthesis

**Development version:** `1.7.0-Alpha-6`
**Tranche:** RS06
**Status:** implementation contract

## Purpose

RS06 exposes the relative terminfo source synthesis engine proven in RS01-RS05
through the existing managed `infocmp` command. The command remains a thin
adapter over `Icod.TermInfo.Inspection`; it does not duplicate parent aggregation,
delta, cancellation, or rendering semantics.

## Command form

```text
infocmp -u target parent [parent ...]
```

The first operand is the target. Every later operand is an ordered synthesis
parent. At least one parent is required.

The exact supplied parent operand is passed as
`TerminalDescriptionSourceSynthesisParent.UseName`. Acquiring an alias may return
a description whose canonical `Name` differs from that operand; RS06 preserves
the operand spelling in the emitted `use=` reference.

Duplicate parent reference names are rejected ordinally. The reusable RS01
maximum remains authoritative: one command may supply at most 64 parents under
the default command policy.

## Database acquisition

Database selection follows the already-frozen `infocmp` split:

```text
-A directory    target database
-B directory    parent database
```

`-A` applies only to the first operand. `-B` applies to every parent operand.
Without the corresponding option, that side uses the normal Runtime system
provider. Neither option mutates `TERMINFO` or any other process environment
variable.

Acquisition failures retain the existing controlled `INFOCMP0002` /
`INFOCMP0003` diagnostic paths and status `1`.

## Rendering controls

Relative synthesis accepts the existing source presentation controls:

```text
-0
-1
-w width
-s d|i|l|c
```

`-w` remains incompatible with `-0` and `-1`, exactly as in ordinary source
listing. The command maps these values directly into
`TerminalDescriptionSourceSynthesisOptions`.

## Extended capabilities

`-x` maps to
`TerminalDescriptionSourceSynthesisOptions.IncludeExtendedCapabilities`.

Without `-x`, RS06 does not claim that extended state is irrelevant. The
reusable RS03 safety rule remains authoritative: if reproducing the target
requires a local extended declaration or cancellation, synthesis fails with a
controlled `INFOCMP0004` operational diagnostic rather than emitting source that
would resolve to different semantics.

With `-x`, required local extended Boolean, numeric, and string declarations,
overrides, kind changes, and cancellations may be emitted.

## Comparison-option interaction

Current ncurses documents `-c -u` as relative rewriting of the first entry using
the second as a building block. RS06 therefore freezes:

```text
-u          relative synthesis
-c -u       accepted synonym for relative synthesis
-d -u       usage error
-n -u       usage error
-q -u       usage error
```

`-c` is discarded after it selects the compatible synthesis form; it does not
alter synthesized source.

Without `-u`, the existing comparison behavior remains unchanged.

## Command-layer composition

The command performs only:

1. option parsing and validation;
2. target acquisition;
3. ordered parent acquisition;
4. construction of synthesis parent descriptors using exact operand spelling;
5. construction of `TerminalDescriptionSourceSynthesisOptions`;
6. delegation to `TerminalDescriptionSourceSynthesizer.Synthesize`;
7. output and diagnostic/status mapping.

All capability merge rules remain in Inspection.

## Router behavior

`icod-terminfo` requires no second implementation. Its existing dispatch path
forwards:

```text
icod-terminfo infocmp -u target parent [parent ...]
```

to the same `Icod.TermInfo.InfoCmp.Command` entry point. RS06 adds a router
regression gate that compares direct and routed synthesis output, diagnostics,
and exit status byte-for-byte.

## Exit statuses

```text
0    successful synthesis
1    acquisition or operational synthesis failure
2    usage error
130  cancellation
```

## Verification gates

RS06 command tests cover:

- separate `-A` target and `-B` parent databases;
- one and multiple ordered parents;
- alias/reference spelling fidelity;
- source parser/resolver semantic round-trip of command output;
- `-c -u` compatibility;
- rejection of `-d -u`, `-n -u`, and `-q -u`;
- source layout, width, and ordering controls;
- semantically safe `-x` handling;
- missing-parent and duplicate-reference validation;
- router dispatch equivalence;
- help and coordinated `1.7.0-Alpha-6` version output.

## Dependency boundary

RS06 adds no public library API. `Icod.TermInfo.Inspection` retains its
Runtime-and-Source-only production dependency graph. Compiler use remains test
and database-fixture infrastructure only.

## Next tranche

RS07 adds deterministic property/fuzz coverage, pinned ncurses differential
fixtures, and hostile/pathological synthesis hardening. RS06 does not pull that
work forward.
