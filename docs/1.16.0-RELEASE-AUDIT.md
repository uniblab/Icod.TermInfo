# Icod.TermInfo 1.16.0 release audit

**Status:** HW08 / Alpha-8 accepted; `1.16.0` stable identity promoted; exact stable qualification pending.
**Publication:** no merge, tag, or release publication has been performed.

## Product contract

This is the hashed-writer-only release. The optional BerkeleyDb package adds
deterministic whole-file Hash-v9 publication and `tic` adds explicit
`--database-format directory|hashed` selection. Existing reading, Runtime
discovery, and JSON contracts are preserved. Migration and catalog automation
remain deferred to 1.17.

The writer uses exact UTF-8 logical identities, little-endian 4096-byte pages,
mask-addressed power-of-two primary buckets, collision chains, and overflow.
It validates compiled identities, enforces configured record/image/parser
limits, and stages, flushes, reopens, verifies, then commits by a same-directory
move under a persistent cooperative lock. The writing guide documents
overwrite, errors, cancellation, metadata, filesystem scope, and exclusions.

## Freeze and distribution

- Twelve public BerkeleyDb types: the unchanged nine-type reader plus the three
  approved writer types. The managed verifier proves exact 1.15 reconstruction.
- Equivalent net8.0/net9.0/net10.0 APIs and assembly identity `1.0.0.0`.
- Runtime-only BerkeleyDb dependency; no Compiler dependency or native assets.
- Seven coordinated nupkg and six reusable-library snupkg artifacts, with exact
  contents, XML documentation, licenses, symbols, and Source Link verification.
- Five commands and six archive RIDs: Windows/Linux/macOS, each x64/ARM64.
- A deterministic public-writer sample and isolated package-only consumer
  cover publication, aliases, reordered input, replacement, refusal, and cancellation.

LGPL-3.0-or-later package metadata is retained. Native Berkeley DB/ncurses are
qualification tools only; this release introduces no native code or runtime
dependency into production packages.
