## Accepted package boundary

HDB01 adds:

```text
Icod.TermInfo.BerkeleyDb
tests/Icod.TermInfo.BerkeleyDb.Tests
```

The accepted package contract is:

- `net8.0;net9.0;net10.0`;
- C# 13;
- reusable assembly identity `1.0.0.0`;
- LGPL-3.0-or-later package licensing for the Icod implementation;
- direct dependency on `Icod.TermInfo` only;
- no third-party runtime package dependency;
- no native Berkeley DB library;
- no RID-specific native assets;
- no exported acquisition/provider API yet;
- cross-TFM public API equivalence;
- coordinated package production and exact package verification.

The package is an Icod-managed implementation boundary. It is not a wrapper or redistribution of Oracle Berkeley DB.

## HDB02 handoff

HDB02 may now productionize the validated storage logic behind an **internal-only** reader. Its boundary is:

```text
supported Berkeley DB Hash-v9 file
          |
          v
validated internal page reader
          |
          v
exact key -> opaque value bytes
```

HDB02 does not own ncurses marker-2/marker-0 resolution, `TerminalDescription`, provider caching, or public acquisition APIs. Those remain HDB03 responsibilities.

The HDB00 research probe remains evidence/oracle code; production HDB02 behavior is re-established test-first rather than copied blindly.
