## Purpose

Version 1.6.0 adds opt-in historical termcap interoperability and two conversion
commands without changing the frozen Runtime, Source, Compiler, or Inspection
contracts or the established `tic`, `infocmp`, and `toe` semantics.

The stable release promotes the TC08-frozen `1.6.0-Alpha-8` code/API/package/CLI
surface to `1.6.0`. No production semantic or public API change belongs in this
finalization step.

## Coordinated version contract

`Directory.Build.props` SHALL declare exactly one coordinated release value:

```text
IcodTermInfoSuiteVersion = 1.6.0
```

The five reusable libraries SHALL consume it for `Version` and `PackageVersion`.
The five standalone command projects SHALL consume it for `Version` and remain
non-packable. `Icod.TermInfo.Tools` SHALL consume it for both `Version` and
`PackageVersion`.

No coordinated project SHALL introduce an independent current-release version
literal.

All five reusable assemblies SHALL retain `AssemblyVersion` `1.0.0.0` and remain
unsigned.

## Termcap interoperability contract

The stable `Icod.TermInfo.Termcap` package includes the TC01-TC06 reusable
surface frozen by TC08:

- bounded conventional termcap parsing;
- Runtime-derived two-character capability classification;
- bounded `tc=` inheritance, cancellation, cycle, and depth handling;
- conversion to the canonical Runtime `TerminalDescription` model with explicit
  loss diagnostics;
- reverse representability analysis and deterministic termcap rendering;
- explicit opt-in `TERMCAP` / `TERMPATH` acquisition through caller-controlled
  environment and file-provider seams.

Termcap remains opt-in and SHALL NOT replace or join ordinary Runtime `TERMINFO`
discovery merely because the package is referenced.

## Command contract

The stable command suite contains five non-packable .NET 10 command projects:

```text
tic
infocmp
toe
captoinfo
infotocap
```

`tic`, `infocmp`, and `toe` retain the frozen 1.4 semantic and CLI contracts.
`captoinfo` and `infotocap` retain the TC07 composition contracts frozen by TC08.
No command project SHALL depend on another command project.

Conversion output represents effective resolved state. Comments, original source
formatting, cancellation/disabled declarations, and original `tc=` / `use=`
ancestry are not reconstructed. Conversion loss or unrepresentability SHALL be
reported rather than silently hidden.

## Router and standalone distribution

`Icod.TermInfo.Tools` SHALL remain a `net10.0` .NET tool package exposing exactly
one unambiguous command:

```text

```

It SHALL route all five commands in-process without duplicating command-specific
option parsing or terminfo/termcap semantics.

The six framework-dependent standalone archives SHALL continue to expose the five
traditional command names directly for:

```text
win-x64
win-arm64
linux-x64
linux-arm64
osx-x64
osx-arm64
```

Both the installed router package and the matching-host standalone archives SHALL
execute real conversion smoke in addition to version checks.
