# Icod.TermInfo 1.0.0 Contract Audit

**Tranche:** T45 — 1.0.0 Completion Gate
**Package version:** `1.0.0`
**Assembly version:** `1.0.0.0`
**Targets:** `net8.0`, `net10.0`
**Host CI families:** Windows, Linux, macOS
**Status:** Release sign-off pending

This document defines the final 1.0 release evidence. Its presence does not claim
that the current commit has passed the external/human-owned gates below.

The release is complete only when the exact `main` commit carrying this contract
passes every required gate and that same commit is tagged `v1.0.0`.

## 1. Production scope freeze

T45 changes no production runtime file under `src/`.

The 1.0 runtime contract remains the combined semantic/acquisition work completed
through 0.9 and hardened during T42-T44:

- immutable terminal descriptions;
- complete standard capability metadata and enumeration;
- standard and extended Boolean/numeric/string semantics;
- signed 32-bit numerics;
- reversible Latin-1 compiled capability strings;
- terminfo parameter parsing/evaluation;
- padding-aware output;
- semantic indexed/direct color helpers;
- built-in ANSI, DEC, xterm, Windows Console, and Windows Terminal profiles;
- conventional compiled terminfo parsing;
- explicit directory acquisition;
- deterministic `TERMINFO`, `TERMINFO_DIRS`, user, and system discovery;
- provider-local successful-entry caching with retryable misses/failures;
- explicit provider composition and immutable built-in fallback.

No live session ownership, PTY/ConPTY lifecycle, curses/UI, input decoder,
terminal probing, source-language tooling, hashed database provider, terminal
emulator, or graphics protocol is added by 1.0.
