# Icod.TermInfo 0.8.0 T27 — Windows Console (`winconsole`)

T27 adds the authoritative ncurses `winconsole` identity. The recorded source
is ncurses `terminfo.src` revision `1.1267`, dated `2026-08-14`, entry
`winconsole|Windows 10 new console`.

`TerminalProfiles.WinConsole` is descriptive data only. Accessing it does not
enable Windows virtual-terminal processing and does not call Windows Console
mode APIs. Applications that own a console handle continue to use
`WindowsVirtualTerminal` explicitly when they choose to enable VT processing.

The canonical name is exactly `winconsole`; there are no aliases. T27 does not
invent `conhost`, `windows-console`, or a direct-color Windows Console identity.

The source inherits ANSI/ECMA, VT220, and xterm function-key fragments. T27
records the retained effective values and materializes every inherited target
which the source cancels. The direct entry then applies its overrides and T26
cancellations. This includes `ncv`, `blink`, `invis`, `ich1`, `rmir`, `rmpch`,
`smir`, and `smpch`; the inherited `vt220+ufkeys` cancellation of `kf5` is also
represented explicitly.

The final profile exposes eight colors, 64 color pairs, no `ncv` value, and the
genuine extensions `AX` (Boolean) and `U8#1` (numeric). F13–F24 use modifier
code 2, F25–F36 code 3, F37–F48 code 4, and F49–F60 code 7, exactly as the
source entry specifies.

T27 does not implement `ms-terminal` or `ms-terminal-direct`; those remain T28.
It does not use `WT_SESSION`, `WT_PROFILE_ID`, or `COLORTERM` as identity, and
it does not add arbitrary compiled-database loading.
