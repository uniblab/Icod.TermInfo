## Purpose and scope

HDB08 closes the distribution qualification gap for the accepted managed,
read-only Berkeley DB Hash-v9 acquisition feature. It adds an exact managed C#
package verifier and consumes one canonical package set on Windows, Linux, and
macOS. It preserves the established six-RID matching-host archive matrix.

HDB08 is qualification-only. The accepted HDB07C head remains the behavior
boundary. HDB08 adds no acquisition feature, public API, package dependency,
command option, JSON field/schema, native runtime, writer, transaction,
environment, recovery, repair path, or broader encoding/format claim.

## Preserved boundaries

HDB08 preserves:

- the public API and reusable assembly version `1.0.0.0`;
- the exact `Icod.TermInfo.BerkeleyDb --> Icod.TermInfo` dependency direction;
- Runtime and Inspection independence from BerkeleyDb;
- the HDB07C lookup, catalog, acquisition, parsing, and exception behavior;
- frozen JSON schemas and existing command behavior;
- pure-managed deployment with no native library or runtime-specific asset;
- the read-only boundary and absence of writer/lifecycle APIs; and
- the stated residual limits for observation races, encodings, and Hash-v9
  format coverage.

No Python, C, or C++ source or dependency was added. New implementation is C#,
Windows PowerShell 5.1-compatible orchestration, and GitHub Actions YAML.
