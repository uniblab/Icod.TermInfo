# Icod.TermInfo 1.7.0 RS07 — Differential Validation, Fuzzing, and Hardening

**Development version:** `1.7.0-Alpha-7`
**Tranche:** RS07
**Status:** implementation contract
**Primary package:** `Icod.TermInfo.Inspection`
**Primary command:** `infocmp -u`

---

## 1. Purpose

RS01 through RS06 established the reusable relative-source synthesis contract,
standard and extended delta semantics, ordered parent precedence, deterministic
rendering, semantic Source/Compiler round trips, and the `infocmp -u` command
adapter. RS07 does not enlarge that contract. It subjects the frozen behavior to
three independent hardening paths:

1. deterministic generated-state/property tests;
2. a pinned ncurses `infocmp -u` semantic differential corpus;
3. hostile and pathological boundary tests.

The objective is semantic confidence rather than textual imitation. Icod output
may differ from ncurses in ordering, wrapping, comments, whitespace, or escape
presentation when both forms resolve to the same effective target description.

---

## 2. Version and dependency boundary

RS07 advances the coordinated repository version to:

```text
1.7.0-Alpha-7
```

No public API is added. Runtime, Source, Compiler, Inspection, and Termcap
assembly versions remain `1.0.0.0` and their previously frozen public surfaces
remain unchanged.

Production dependency direction is unchanged:

```text
Icod.TermInfo.Inspection
    -> Icod.TermInfo.Source
    -> Icod.TermInfo
```

Compiler use remains test-only from Inspection's perspective. The ncurses tool
is a corpus-generation reference only and is never a production or normal-CI
dependency.

## 3. Deterministic generated-state testing

`RS07ContractTests` exercises a deterministic generated state space. It does not
use `System.Random`; a small fixed xorshift generator keeps each case stable
across target frameworks, operating systems, cultures, and runtime revisions.

The generated case space includes:

- one through four ordered parents;
- target and parent Boolean capability combinations;
- numeric values at ordinary and boundary magnitudes;
- escaped strings containing commas, backslashes, CR/LF, and ESC;
- parameterized cursor-address strings;
- extended Boolean, numeric, and string capabilities;
- extended value-kind changes;
- parent collisions;
- target omissions which require inherited cancellations;
- alias-spelled parent references.

For each accepted case the permanent invariant is:

```text
TerminalDescription target
+ ordered effective parents
    -> Synthesize
    -> append effective parent source
    -> TermInfoSourceParser
    -> TermInfoSourceResolver
    -> TerminalDescriptionComparer
    -> semantic equality
```

The same case is synthesized twice and must produce byte-identical LF output.

### 3.1 Reproducible failures

Every generated case has a fixed 32-bit seed. A failure message reports the seed
in hexadecimal form, for example:

```text
reproducible seed=0x17070001
```

A failing seed can therefore be promoted directly into a dedicated regression
fixture without relying on nondeterministic fuzz reproduction.

## 4. Pinned ncurses semantic differential corpus

RS07 captures a checked-in reference corpus under:

```text
tests/Icod.TermInfo.Inspection.Tests/fixtures/
    rs07-ncurses-6.5.20250216/
```

The capture environment is intentionally pinned:

```text
ncurses              6.5.20250216
host                  Debian GNU/Linux 13 (trixie), x86_64
terminfo database     /usr/share/terminfo
full-entry capture    infocmp -x -1 TERMINAL
relative capture      infocmp -x -u TARGET PARENT [PARENT ...]
```

The exact reference is retained even when newer ncurses releases exist. Corpus
refresh is an explicit reviewed action rather than an automatic consequence of
a host-package update.

The corpus contains representative cases for:

- `xterm-256color` relative to `xterm`;
- `screen-256color` relative to `screen`;
- `tmux-256color` relative to `screen-256color`;
- Linux console relative to `vt100`;
- `vt220` relative to `vt100`;
- `xterm-256color` relative to both `xterm` and `screen-256color`.

This covers xterm, screen, tmux, Linux console, VT-family inheritance,
256-color/extended capabilities, cancellation-heavy rewrites, and ordered
multi-parent synthesis.

### 4.1 Normal-CI differential gate

Normal CI does not execute ncurses. The checked-in corpus is self-contained.
Tests:

1. parse the pinned effective entries through `TermInfoSourceParser`;
2. resolve the target and parent descriptions through Icod Source;
3. combine the pinned ncurses relative source with equivalent parent source;
4. resolve and compare that result with the effective target;
5. synthesize the same case through Icod;
6. resolve and compare the Icod result with the same target.

Both paths must resolve semantically to the target. Byte-for-byte equality between
ncurses and Icod source text is explicitly not required.

### 4.2 Corpus regeneration

The fixture directory contains `regenerate.sh`. It refuses to regenerate unless:

```text
infocmp -V
```

returns exactly:

```text
ncurses 6.5.20250216
```

This prevents accidental corpus drift caused by a different ncurses patch level.

## 5. Pathological and hostile cases

RS07 adds explicit regression coverage for the limits already frozen by earlier
tranches.

### 5.1 Maximum parent count

The synthesizer is exercised with exactly:

```text
TerminalDescriptionSourceSynthesisOptions.MaximumSupportedParentCount
    == 256
```

parents under an option value that permits the full supported limit. Output must
retain the first-through-last caller order without pruning or reordering.

### 5.2 Large extended-name union

Four parents contribute 64 disjoint extended capabilities each. A target with
none of them requires 256 local cancellations. The complete source must still
parse, resolve, and compare equal to the target.

### 5.3 Long source strings

A target string larger than 32 KiB is synthesized through canonical wrapping and
must survive parse/resolve semantic round trip without CR injection or value
corruption.

### 5.4 Alias-mediated repeated parent

The same effective parent is supplied under its canonical name and an alias.
Both references must remain in caller order and resolve semantically according to
the RS01/RS04 repeated-parent policy.

### 5.5 Culture stability

A fixed generated case is synthesized under Turkish and French cultures and must
produce identical output.

### 5.6 Command cancellation

A pre-canceled `infocmp -u target parent` invocation must return the established
canceled exit status without writing caller-owned stdout or stderr streams.

## 6. Intentional ncurses presentation differences

RS07 treats the following as presentation-only when semantic resolution remains
equal:

- comments and reconstruction notices;
- physical wrapping;
- indentation and whitespace;
- standard capability ordering selected by Icod renderer policy;
- equivalent source escape spellings;
- decimal versus hexadecimal numeric presentation;
- omission of ncurses-specific explanatory text.

A semantic difference is not presentation-only. Any future corpus case which
resolves differently under the pinned ncurses source and Icod synthesis must be
investigated and either corrected or explicitly documented as an intentional
contract divergence before the gate can pass.

---

## 7. Coding and regression discipline

RS07 test additions follow repository conventions:

- all control-flow bodies use braces;
- multiline invocations close on their own line;
- direct assertion predicate overloads are preferred where available;
- tests do not write to process stdout/stderr;
- deterministic generated failures identify their reproducible seed;
- corpus files are checked in and ordinary tests do not depend on host ncurses.

No `Assert.Single(collection.Where(predicate))` form is introduced; predicate
assertions use the direct collection/predicate overload.

---

## 8. Gate

RS07 is complete when:

- every deterministic generated case round-trips semantically;
- every pinned ncurses case and corresponding Icod case resolve to the same target;
- maximum-parent, large-union, long-string, repeated-parent, culture, and command-
  cancellation tests pass;
- no known semantic divergence remains unexplained;
- Runtime, Source, Compiler, Inspection, and Termcap public contracts remain
  unchanged;
- production packages acquire no ncurses or Compiler dependency through this
  hardening work.

RS08 remains responsible for the final 1.7 Inspection API baseline, package/API
freeze, archive/package verification, release audit, and stable `1.7.0` closure.
