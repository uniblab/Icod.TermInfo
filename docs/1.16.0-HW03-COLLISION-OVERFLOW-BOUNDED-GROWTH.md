## Accepted storage profile

HW03 preserves the canonical HW02 profile:

- Berkeley DB Hash on-disk version 9;
- little-endian metadata;
- 4,096-byte pages;
- the accepted Hash-v9 function and native bucket mask;
- deterministic exact-byte key ordering; and
- deterministic file identifiers derived from the complete ordered records.

Physical pages are allocated in this order:

| Order | Page role | Page type |
| --- | --- | ---: |
| 1 | Metadata | `8` |
| 2 | Contiguous primary hash buckets | `13` |
| 3 | Linked hash continuation pages | `13` |
| 4 | Key/value overflow chains | `7` |

Primary bucket counts remain powers of two. Candidate evaluation begins with
two buckets and doubles the count only while the configured complete-image
budget permits evaluation. The natural layout selects the smallest feasible
power-of-two candidate that removes reducible continuation chains. When the
database-size ceiling prevents that growth, the greatest feasible candidate is
used with deterministic linked continuation pages.

Exact-hash collisions cannot be separated by additional mask bits. They remain
in stable writer-key order and use linked type-13 continuation pages. Primary
pages retain their physical bucket page numbers; continuation pages link with
checked previous/next page numbers and precede every overflow page.

## Inline and overflow boundaries

An item through 1,024 bytes remains a type-1 inline item. An item of 1,025 bytes
or more uses the exact 12-byte type-3 off-page descriptor and one or more
type-7 overflow pages. Each overflow page carries at most 4,070 payload bytes:

| Payload length | Item type | Overflow pages |
| ---: | ---: | ---: |
| 1,024 | `1` | 0 |
| 1,025 | `3` | 1 |
| 4,070 | `3` | 1 |
| 4,071 | `3` | 2 |
| 8,140 | `3` | 2 |

Keys and values receive independent chains. Exact 4,070-byte multiples do not
allocate empty tail pages. Every page, descriptor, link, byte count, page count,
and final image size is preflighted with checked arithmetic before allocating
the image. Cancellation is observed during shape creation, candidate
evaluation, layout finalization, and page writing.
