## Release objective

Version 1.11 adds protocol-neutral persistent-raster lifecycle semantics to `Icod.TermInfo.Inspection`:

- immutable lifecycle evidence with provenance;
- four-state support classification;
- explicit evidence precedence and contradiction preservation;
- deterministic bounded lifecycle requests and plans;
- `TerminalDescription` and ordered database-set composition;
- additive version-3 lifecycle profile/plan JSON;
- package-only downstream qualification; and
- a reusable checked-in lifecycle sample.

Live protocol verification and terminal-side resource/placement ownership remain outside TermInfo.

## Compatibility and dependency boundary

`Icod.TermInfo.Inspection` still depends only on matching Runtime and Source packages. It does not depend on Compiler, Termcap, `Icod.Terminal`, or `Icod.DCurses`.

Version 1.11 adds no live-terminal session ownership. It exposes no terminal image IDs, placement IDs, resource registries, protocol encoders, acknowledgement readers, cursor-coordinate policy, or cleanup executors.

Sixel or other ordinary raster display evidence does not imply persistent resource or placement support.
